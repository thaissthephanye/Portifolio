# Portfólio da Thais Sthephanye

Reuni aqui cinco projetos que fiz para praticar desenvolvimento web, jogos e dados. A página foi feita com HTML, CSS e JavaScript.

## Projetos apresentados

- **Alyson Trilhas:** guia do Brejo Paraibano com filtros e detalhes interativos. [Código](https://github.com/thaissthephanye/alyson-trilhas)
- **LUMIN:** e-commerce com catálogo, carrinho no navegador e checkout simulado. [Código](https://github.com/thaissthephanye/EcommerceLumin)
- **Censo Escolar PB:** [interface React](https://github.com/thaissthephanye/MinhaAppReact) com dados preparados em [Python](https://github.com/thaissthephanye/CensoEscolarDataApp).
- **Code Adventure:** jogo em canvas. [Código](https://github.com/thaissthephanye/code-adventure)
- **Seletor de RPG:** interface de personagens e atributos. [Código](https://github.com/thaissthephanye/rpg-selector)

## Abrir localmente

Abra `index.html` no navegador. O site usa HTML, CSS e JavaScript sem etapa de compilação.
